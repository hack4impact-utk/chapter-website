## Description

Our chapter website, used to share links for students and nonprofits to apply to our organization

## Configuration

Update the `content.json` file in the `src/content` directory with the relevant information.

## Local Development

Install the dependencies:

```sh
pnpm install
```

Start the development server:

```sh
pnpm dev
```

Build the production site:

```sh
pnpm build
```

Preview the production site:

```sh
pnpm preview
```
